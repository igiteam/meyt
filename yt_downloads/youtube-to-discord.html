Set Up a Discord Webhook for YouTube Live Notifications

Follow this step-by-step guide to create a Discord webhook that posts to your server whenever someone goes live on a YouTube channel.

1. Set Up a Discord Webhook

  1. Go to your Discord server and select the desired channel.
  2. Click the gear icon to open channel settings.
  3. Under Integrations, create a new webhook.
  4. Copy the webhook URL; you will use it later.

2. Get YouTube API Access

  1. Go to the Google Cloud Console.
  2. Create a new project or select an existing one.
  3. Enable the YouTube Data API v3 for the project.
  4. Generate an API key:
    • Go to the Credentials page.
    • Click Create credentials and select API Key.
    • Copy the generated API key.

3. Write the Monitoring Script

Use the following Python script to monitor the YouTube channel and post a notification to Discord when a live stream starts:

import requests
import time

# YouTube API key and channel ID
YOUTUBE_API_KEY = 'YOUR_YOUTUBE_API_KEY'
CHANNEL_ID = 'TARGET_CHANNEL_ID'

# Discord webhook URL
DISCORD_WEBHOOK_URL = 'YOUR_DISCORD_WEBHOOK_URL'

def check_live_status():
    url = f"https://www.googleapis.com/youtube/v3/search?part=snippet&channelId={CHANNEL_ID}&type=video&eventType=live&key={YOUTUBE_API_KEY}"
    response = requests.get(url)
    data = response.json()

    if 'items' in data and len(data['items']) > 0:
        # Live video found
        video_id = data['items'][0]['id']['videoId']
        video_url = f"https://www.youtube.com/watch?v={video_id}"
        return video_url
    return None

def post_to_discord(message):
    payload = {"content": message}
    headers = {"Content-Type": "application/json"}
    response = requests.post(DISCORD_WEBHOOK_URL, json=payload, headers=headers)
    return response.status_code

if __name__ == "__main__":
    already_notified = False

    while True:
        live_url = check_live_status()
        if live_url and not already_notified:
            message = f"🔴 **Live Now!**\n{live_url}"
            status = post_to_discord(message)
            if status == 204:  # Successful Discord webhook response
                print("Notification sent.")
                already_notified = True
        elif not live_url:
            already_notified = False  # Reset if no live stream is found

        time.sleep(60)  # Check every minute

4. Run the Script

  1. Save the script in a file, e.g., youtube_to_discord.py.
  2. Install the required libraries: 
    pip install requests
  3. Run the script: 
    python youtube_to_discord.py

5. Deploy for Continuous Monitoring

To keep the script running continuously, consider:

  • Using a cron job (Linux/macOS) or Task Scheduler (Windows).
  • Deploying it to a cloud service like AWS, Google Cloud, or Heroku.

That's it! Now your Discord server will be notified whenever the YouTube channel goes live. 🎉
